# House-Renting-Platform
🏠 House Renting App

📌 Overview

The House Renting App is a web application designed to make the process of finding and renting houses easier and more convenient. Users can browse available properties, view property details, check rental prices, and find houses based on their preferences.

The application provides a simple and user-friendly interface for both tenants looking for houses and property owners who want to list their properties.

🎯 Objectives

- Help users easily find houses available for rent.
- Allow users to search and filter properties based on their requirements.
- Display detailed information about each property.
- Provide property owners with an easy way to list rental houses.
- Reduce the time and effort involved in finding a suitable rental property.
- Provide a simple and responsive user interface.

✨ Features

👤 User Features

- User registration and login
- Browse available houses
- Search for properties
- Filter houses by:
  - Location
  - Price
  - Number of bedrooms
  - Property type
- View detailed property information
- View property images
- Contact property owners
- Save/favorite properties

🏡 Property Owner Features

- Add rental properties
- Upload property images
- Add property details
- Set rental price
- Edit or remove property listings
- Manage listed properties

🛠️ Technologies Used

- Frontend: HTML, CSS, JavaScript / React
- Backend: Node.js / Express
- Database: MongoDB
- Authentication: User authentication system
- Development Tool: VS Code

🚀 Installation and Setup

1. Clone the repository

git clone https://github.com/your-username/house-renting-app.git

2. Navigate to the project folder

cd house-renting-app

3. Install dependencies

npm install

4. Start the application

npm run dev

The application will run locally on the development server.

💻 Usage

1. Open the application.
2. Register or log in as a user.
3. Search for available houses.
4. Apply filters according to your requirements.
5. Select a property to view its details.
6. Contact the property owner for further information.
7. Property owners can log in and add or manage their listings.
